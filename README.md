# payroll-toolkit
Offline Arabic browser tools for payroll calculations and printable change forms.

Open `index.html` directly in a desktop browser. Apps:

- `combined/`: increment and/or promotion arrears on one printed form (the main calculator).
- `allowances/`: increment arrears only (older calculator).
- `promotions/`: promotion arrears only (older calculator).
- `grades/`: grade and stage lookup from a nominal salary.
